## Why it surfaced now

These two files are part of the human's **uncommitted** working tree on
`client-blazor` (branch `feat/task-013-detection-doublons-cda`). The
pre-flight already logged this WIP state ; the build error is a direct
consequence of it. The committed code on that branch builds — only the
new local edits trip S3358.

Same pattern in both : `A ? a : (B ? b : c)`. Refactor options :
- **Local var ladder** — two `if` lines populating `var displayTitle = ...`,
  then render `@displayTitle` (already done lower in `MailReadOnlyView`,
  inconsistent here).
- **Coalesce-style helper** — `string.IsNullOrWhiteSpace` doesn't compose
  with `??`, so introduce a tiny `Coalesce(params string?[] candidates)`
  helper returning the first non-blank, or use
  `new[] { a, b, c }.FirstOrDefault(s => !string.IsNullOrWhiteSpace(s)) ?? "—"`.

After fixing, re-run `/qa` (no `--kill-leftovers` needed unless something
else is squatting the ports).
